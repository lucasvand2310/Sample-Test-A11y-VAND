用語集 (Glossary)

当サイトで使用されている専門用語や技術用語の解説です。

ディレクション集団
プロジェクトの目的を達成するために、制作進行、品質管理、予算管理、ステークホルダーとの調整など、多角的な視点から指揮・統括を行う専門家チームのことです。
UX/UI
UX（User Experience）は「ユーザー体験」、UI（User Interface）は「ユーザーインターフェース」を指します。製品やサービスを通じて得られる体験の質と、それを利用するための接点の設計を意味します。
UX
User Experience（ユーザー体験）の略称。製品やサービスを利用する過程でユーザーが得られる体験や感情、満足度のことを指します。
デジタルサイネージ
屋外・店頭・公共空間・交通機関などで、ディスプレイやプロジェクターなどの電子的な表示機器を使って情報を発信するシステムのことです。
バックエンドシステム
Webサイトやアプリの裏側で動作する、データ処理やデータベース管理などを行うシステムのことです。ユーザーが直接目にすることのないサーバー側の仕組みを指します。
API
Application Programming Interfaceの略。ソフトウェアやプログラム、Webサービスの間をつなぐインターフェースのことです。
iPhone・Androidアプリ
Apple社のiOS（iPhone）やGoogle社のAndroid OSで動作する、スマートフォン・タブレット端末専用的アプリケーションプログラムのことです。
HTML5+CSS3+Javascript
Webサイトを構築するための標準的な技術です。HTMLは「構造」、CSSは「見た目」、JavaScriptは「動きや機能」を主に担当します。
ハイブリッドアプリ
Webの技術（HTML/CSS/JavaScript）を使いつつ、スマートフォンのネイティブ機能も利用できるように構築されたアプリのことです。
MR2GO
Mixed Reality（複合現実）技術を活用した、特定のプロモーションやソリューション向けのアプリケーション基盤またはサービスの名称です。
AR
AR（Augmented Reality：拡張現実）技術を使い、現実世界にデジタル情報を重ね合わせて表示することで、商品の体験や宣伝を行うアプリのことです。
ラボ型オフショア開発
開発コストの低い海外（オフショア）の企業と提携し、一定期間、自社専用のエンジニアチームを確保して開発を行う形態のことです。
オフショア開発
Webシステムやアプリなどの開発業務を、人件費の安い海外の企業や子会社に委託することです。
